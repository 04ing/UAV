## 1. 系统架构概述

```
┌──────────────────────────────────────────────────────────────┐
│                        真实无人机 (DJI M350 / M30T)             │
│                                                              │
│  机载 SDK / 上云网关  ──→  MQTT / HTTP  ──→  数据转发脚本      │
└──────────────────────────────────┬───────────────────────────┘
                                   │
                    HTTP POST / WebSocket
                                   │
                                   ▼
┌──────────────────────────────────────────────────────────────┐
│                    巡检系统后端 (Express)                      │
│                                                              │
│  POST /api/drones/:id/telemetry    → 遥测入库 + WS 推送       │
│  POST /api/alarms/upload            → 告警入库 + WS 推送       │
│  POST /api/drones/upload            → 机队注册                 │
│  WS   /api/drones/:id/telemetry     → 遥测实时订阅             │
│  WS   /ws/alarm                     → 告警实时订阅             │
│  WS   /ws/video                     → 视频帧订阅              │
│                                                              │
│  EventEmitter → WebSocket 广播 → 前端大屏 / GIS / 飞控页       │
└──────────────────────────────────┬───────────────────────────┘
                                   │
                                   ▼
┌──────────────────────────────────────────────────────────────┐
│                      前端可视化 (浏览器)                      │
│                                                              │
│  总览大屏 / 飞控监控 / GIS地图 / 告警中心 / 接口管理           │
└──────────────────────────────────────────────────────────────┘
```

### 核心数据流

| 数据类型 | 上行（无人机→系统） | 下行（系统→前端） |
|----------|---------------------|-------------------|
| **遥测数据** | `POST /api/drones/:id/telemetry` | WebSocket `/api/drones/:id/telemetry` |
| **告警事件** | `POST /api/alarms/upload` | WebSocket `/ws/alarm` |
| **视频帧** | `POST` → EventEmitter `video-frame` | WebSocket `/ws/video` |
| **指令下发** | `POST /api/drones/:id/return-home` | — |

## 4. 接入方式一：HTTP REST 上报遥测数据

这是最核心的接入接口。无人机 / 上云网关每隔 1~3 秒调用一次，将实时遥测数据上报到系统。

### 接口详情

```
POST /api/drones/:id/telemetry
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `lat` | number | ✅ | 纬度 (WGS84) |
| `lng` | number | ✅ | 经度 (WGS84) |
| `battery` | number | ❌ | 电量百分比 (0~100) |
| `signal` | string | ❌ | 信号强度描述（"强"/"中"/"弱"） |
| `altitude` | number | ❌ | 海拔高度 (米) |
| `speed` | number | ❌ | 飞行速度 (m/s) |
| `heading` | number | ❌ | 航向角 (0~360) |
| `status` | string | ❌ | 飞行状态 (`idle`/`inspecting`/`returning`/`offline`) |

### curl 示例

```bash
curl -X POST http://47.103.29.77:4000/api/drones/DRONE-001/telemetry \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "lat": 30.5986,
    "lng": 114.3052,
    "battery": 78,
    "signal": "强",
    "altitude": 120,
    "speed": 8,
    "heading": 45,
    "status": "inspecting"
  }'
```

### 响应

```json
{
  "code": 0,
  "msg": "遥测数据更新成功",
  "data": {
    "id": "DRONE-001",
    "model": "DJI M350 RTK",
    "lat": 30.5986,
    "lng": 114.3052,
    "battery": 78,
    "signal": "强",
    "altitude": 120,
    "speed": 8,
    "heading": 45,
    "status": "inspecting",
    "lastUpdate": "2026-08-04T10:30:00.000Z"
  }
}
```

> **实时推送**：每次 POST 成功后，系统通过 EventEmitter → WebSocket 自动推送到前端，前端地图和飞控页面会实时更新无人机位置。

### 自动返航机制

系统在遥测数据更新时自动检测电量：

- 电量 ≤ 25% 且状态为 `inspecting` → 自动切换为 `returning`
- 电量 ≤ 0% → 切换为 `offline`，生成 `critical` 级紧急告警

无需额外调用返航接口，系统会自动处理。

## 5. 接入方式二：批量上传告警事件

当无人机检测到异常（低电量、电机故障、GPS丢失等），可批量上报告警到系统。

### 接口详情

```
POST /api/alarms/upload
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `alarms` | array | ✅ | 告警数组 |
| `alarms[].type` | string | ✅ | 告警类型（如 "低电量告警"、"电机故障"） |
| `alarms[].severity` | string | ❌ | 严重程度：`low`/`medium`/`warning`/`critical`（默认 `medium`） |
| `alarms[].droneId` | string | ✅ | 无人机 ID |
| `alarms[].lat` | number | ✅ | 告警位置纬度 |
| `alarms[].lng` | number | ✅ | 告警位置经度 |
| `alarms[].description` | string | ❌ | 告警描述 |
| `alarms[].imageBase64` | string | ❌ | 现场截图（Base64） |

### curl 示例

```bash
curl -X POST http://47.103.29.77:4000/api/alarms/upload \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "alarms": [
      {
        "type": "低电量告警",
        "severity": "warning",
        "droneId": "DRONE-001",
        "lat": 30.5986,
        "lng": 114.3052,
        "description": "电量低于25%，已触发自动返航"
      },
      {
        "type": "电机故障",
        "severity": "critical",
        "droneId": "DRONE-002",
        "lat": 30.6012,
        "lng": 114.3025,
        "description": "2号电机转速异常，已执行紧急返航"
      }
    ]
  }'
```

### 响应

```json
{
  "code": 0,
  "msg": "成功上传 2 条告警",
  "data": {
    "total": 2,
    "uploaded": ["ALARM-016", "ALARM-017"]
  }
}
```

> **实时推送**：告警上传后，系统通过 WebSocket `/ws/alarm` 自动推送到前端告警中心。

## 8. 故障注入与自动返航测试

系统内置故障模拟引擎，可用于测试告警和返航逻辑。

### 8.1 触发故障

```bash
curl -X POST http://47.103.29.77:4000/api/drones/DRONE-001/fault \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"faultType": "low_battery"}'
```

**支持的故障类型：**

| 故障类型 | 值 | 自动动作 |
|----------|-----|----------|
| 电机故障 | `motor_failure` | 自动返航，速度降低 |
| 低电量 | `low_battery` | 自动返航 |
| GPS丢失 | `gps_lost` | 自动返航 |
| 信号丢失 | `signal_lost` | 自动返航 |
| 障碍物 | `obstacle` | 悬停 |

### 8.2 查询故障状态

```bash
curl http://47.103.29.77:4000/api/drones/DRONE-001/fault \
  -H "Authorization: Bearer <token>"
```

### 8.3 清除故障（恢复巡检）

```bash
curl -X DELETE http://47.103.29.77:4000/api/drones/DRONE-001/fault \
  -H "Authorization: Bearer <token>"
```

### 8.4 电量耗尽紧急告警

当无人机电量降至 0% 时，系统自动：

1. 状态切换为 `offline`
2. 生成 `critical` 级紧急告警（类型：无人机失联）
3. 记录最后已知位置（用于搜救）
4. 通过 WebSocket 推送紧急通知

## 9. 完整集成代码示例

### 9.1 Python（适用于树莓派 / 机载网关）

```python
"""
无人机遥测数据上报脚本
适用于 DJI Onboard SDK / PSDK + 树莓派
"""
import requests
import time
import json
from datetime import datetime

SERVER_URL = "http://47.103.29.77:4000"
DRONE_ID = "DRONE-001"
USERNAME = "admin"
PASSWORD = "admin123"

class UAVClient:
    def __init__(self):
        self.token = None
        self.login()

    def login(self):
        """获取 JWT Token"""
        resp = requests.post(
            f"{SERVER_URL}/api/auth/login",
            json={"username": USERNAME, "password": PASSWORD}
        )
        data = resp.json()
        if data["code"] == 0:
            self.token = data["data"]["token"]
            print(f"[✓] 登录成功，Token 有效期 8 小时")
        else:
            raise Exception(f"登录失败: {data['msg']}")

    def report_telemetry(self, lat, lng, battery, altitude, speed, heading, status="inspecting"):
        """上报遥测数据（建议每 1-3 秒调用一次）"""
        resp = requests.post(
            f"{SERVER_URL}/api/drones/{DRONE_ID}/telemetry",
            headers={
                "Content-Type": "application/json",
                "Authorization": f"Bearer {self.token}"
            },
            json={
                "lat": lat,
                "lng": lng,
                "battery": battery,
                "altitude": altitude,
                "speed": speed,
                "heading": heading,
                "status": status
            }
        )
        result = resp.json()
        if result["code"] == 0:
            # 检查系统是否自动切换了状态（如低电量返航）
            new_status = result["data"].get("status", status)
            if new_status != status:
                print(f"[!] 系统自动切换状态: {status} → {new_status}")
            return result["data"]
        else:
            print(f"[✗] 遥测上报失败: {result['msg']}")
            return None

    def upload_alarm(self, alarm_type, severity, lat, lng, description=""):
        """上传告警"""
        resp = requests.post(
            f"{SERVER_URL}/api/alarms/upload",
            headers={
                "Content-Type": "application/json",
                "Authorization": f"Bearer {self.token}"
            },
            json={
                "alarms": [{
                    "type": alarm_type,
                    "severity": severity,
                    "droneId": DRONE_ID,
                    "lat": lat,
                    "lng": lng,
                    "description": description
                }]
            }
        )
        result = resp.json()
        if result["code"] == 0:
            print(f"[✓] 告警已上传: {alarm_type}")
        return result

    def return_home(self):
        """一键返航"""
        resp = requests.post(
            f"{SERVER_URL}/api/drones/{DRONE_ID}/return-home",
            headers={"Authorization": f"Bearer {self.token}"}
        )
        return resp.json()


# ============ 使用示例 ============
if __name__ == "__main__":
    client = UAVClient()

    # 模拟飞行循环（实际使用时替换为 SDK 获取的真实数据）
    for i in range(100):
        # 从 DJI SDK 获取真实遥测数据
        lat = 30.5980 + i * 0.0001    # 替换为 drone.get_lat()
        lng = 114.3050 + i * 0.0001   # 替换为 drone.get_lng()
        battery = 95 - i * 0.5        # 替换为 drone.get_battery()
        altitude = 120                # 替换为 drone.get_altitude()
        speed = 8                     # 替换为 drone.get_speed()
        heading = 45                  # 替换为 drone.get_heading()

        # 上报遥测
        drone_state = client.report_telemetry(
            lat, lng, battery, altitude, speed, heading
        )

        # 低电量自动告警
        if battery <= 25 and i == 50:
            client.upload_alarm(
                "低电量告警", "warning",
                lat, lng,
                f"电量 {battery}%，已触发自动返航"
            )

        # 电量耗尽紧急告警
        if battery <= 0:
            client.upload_alarm(
                "无人机失联", "critical",
                lat, lng,
                "电量耗尽坠毁，请立即组织救援"
            )
            break

        time.sleep(2)  # 每 2 秒上报一次
```

### 9.2 Node.js（适用于上云网关 / 服务器端转发）

```javascript
/**
 * 无人机数据转发服务
 * 从 DJI Cloud API MQTT Broker 订阅数据，转发到巡检系统
 */
const axios = require('axios');
const mqtt = require('mqtt');

const SERVER_URL = 'http://47.103.29.77:4000';
const DRONE_ID_MAP = { 'sn_aabbcc': 'DRONE-001', 'sn_xxyyzz': 'DRONE-002' };

// 1. 登录获取 Token
async function login() {
  const { data } = await axios.post(`${SERVER_URL}/api/auth/login`, {
    username: 'admin',
    password: 'admin123',
  });
  return data.data.token;
}

// 2. 创建带认证的 HTTP 客户端
function createClient(token) {
  return axios.create({
    baseURL: SERVER_URL,
    headers: { Authorization: `Bearer ${token}` },
    timeout: 10000,
  });
}

// 3. 上报遥测
async function reportTelemetry(client, droneId, telemetry) {
  try {
    const { data } = await client.post(`/api/drones/${droneId}/telemetry`, {
      lat: telemetry.latitude,
      lng: telemetry.longitude,
      battery: telemetry.battery_percent,
      altitude: telemetry.height,
      speed: telemetry.horizontal_speed,
      heading: telemetry.heading,
      status: telemetry.mode === 'return' ? 'returning' : 'inspecting',
    });
    return data.data;
  } catch (err) {
    console.error(`[遥测上报失败] ${droneId}:`, err.message);
  }
}

// 4. 上报告警
async function uploadAlarm(client, droneId, alarm) {
  try {
    await client.post('/api/alarms/upload', {
      alarms: [{
        type: alarm.type,
        severity: alarm.severity,
        droneId: droneId,
        lat: alarm.lat,
        lng: alarm.lng,
        description: alarm.message,
      }],
    });
    console.log(`[告警已上报] ${droneId}: ${alarm.type}`);
  } catch (err) {
    console.error(`[告警上报失败] ${droneId}:`, err.message);
  }
}

// 5. 主流程：连接 MQTT Broker，订阅 DJI Cloud API 数据
async function main() {
  const token = await login();
  const client = createClient(token);
  console.log('[✓] 已登录巡检系统');

  // 连接 DJI Cloud API MQTT Broker
  const mqttClient = mqtt.connect('mqtt://your-dji-cloud-broker:1883');

  mqttClient.on('connect', () => {
    // 订阅遥测话题
    mqttClient.subscribe('thing/product/+/osd');
    console.log('[✓] 已连接 MQTT Broker');
  });

  mqttClient.on('message', async (topic, message) => {
    // 解析 DJI 上云 API 数据格式
    const data = JSON.parse(message.toString());
    const sn = topic.split('/')[2];
    const droneId = DRONE_ID_MAP[sn];

    if (!droneId) return;

    // 转发遥测数据
    if (data.data && data.data.latitude) {
      await reportTelemetry(client, droneId, data.data);
    }

    // 转发告警事件
    if (data.method && data.method.includes('warning')) {
      await uploadAlarm(client, droneId, {
        type: data.method,
        severity: 'warning',
        lat: data.data.latitude,
        lng: data.data.longitude,
        message: data.data.message,
      });
    }
  });
}

main().catch(console.error);
```

```json
  "lng": 114.3052,
  "altitude": 120,
  "speed": 8,
  "heading": 45,
  "lastUpdate": "2026-08-04T10:30:00.000Z"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `status` | string | `idle`(待机) / `inspecting`(巡检中) / `returning`(返航中) / `offline`(离线) |
| `battery` | number | 0~100，≤25% 触发返航，≤0% 触发坠毁告警 |
| `signal` | string | "强" / "中" / "弱" |

### 10.2 告警数据结构（Alarm）

```json
{
  "id": "ALARM-016",
  "type": "低电量告警",
  "severity": "warning",
  "droneId": "DRONE-001",
  "lat": 30.5986,
  "lng": 114.3052,
  "timestamp": "2026-08-04T10:30:00.000Z",
  "status": "pending",
  "description": "电量低于25%，已触发自动返航",
  "emergency": false
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `severity` | string | `low` / `medium` / `warning` / `critical` |
| `status` | string | `pending`(待处理) / `resolved`(已解决) |
| `emergency` | boolean | 仅坠毁告警为 `true`，包含 `lastKnownPosition` |

### 10.3 状态流转图

```
          注册无人机               开始巡检
 idle ──────────→ idle ──────────→ inspecting
                      ↑                  │
                      │            电量≤25% │  故障触发
                      │                  ↓
                      └──────── returning
                                    │
                              电量≤0% │
                                    ↓
                                 offline (紧急告警)
```

## 11. 常见问题排查

### Q1: 接口返回 401 Unauthorized

**原因**：Token 过期或未携带。

**解决**：重新登录获取 Token，有效期 8 小时。

```bash
# 重新获取 Token
curl -X POST http://47.103.29.77:4000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

### Q2: 遥测上报返回 404

**原因**：无人机 ID 未在系统中注册。

**解决**：先调用 `POST /api/drones/upload` 注册无人机。

### Q3: 前端地图看不到无人机位置

**排查步骤**：

1. 确认遥测 POST 返回 `code: 0`
2. 检查 `lat` / `lng` 是否为有效数值（非 null / NaN）
3. 确认前端已建立 WebSocket 连接（浏览器控制台查看）
4. 检查 `lastUpdate` 时间戳是否为最新

### Q4: 低电量时没有自动返航

**检查清单**：

- 无人机的 `status` 字段是否为 `inspecting`（只有巡检中才会自动返航）
- `battery` 值是否 ≤ 25（数值类型，非字符串）
- 查看故障状态：`GET /api/drones/:id/fault`

### Q5: WebSocket 连接立即断开

**原因**：WebSocket 路径不匹配。

**正确路径**：

| 频道 | 路径 |
|------|------|
| 遥测 | `ws://host/api/drones/DRONE-001/telemetry` |
| 告警 | `ws://host/ws/alarm` |
| 视频 | `ws://host/ws/video` |

### Q6: 生产环境端口访问不了

**排查**：

1. 阿里云安全组：放行 4000 端口（TCP）
2. 服务器防火墙：`ufw allow 4000` 或 `firewall-cmd --add-port=4000/tcp`
3. PM2 进程状态：`pm2 status` 确认 `uav-backend` 为 `online`
4. 查看日志：`pm2 logs uav-backend --lines 50`
